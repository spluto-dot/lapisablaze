libTAS

Particularmente, eu gosto de testar tudo no Windows com calma, faço todos os tipos de testes e, só depois, vou para o Linux com os jogos instalados, prontos para rodar e criar o MOVIE em si.

https://github.com/TASEmulators/pcem/releases/tag/17%2Bst-1

Dentro do Linux, você precisa criar a pasta /home/<USER>/.pcem. Dentro dela, os arquivos são iguais aos do Windows.
No WIN95.cfg, você deve modificar o hdc_fn para apontar para o windows95.img. Ainda no WIN95.cfg configure também o cdrom_drive para 200, e, caso vá usar alguma ISO, utilize o parâmetro cdrom_path.
Por fim, abra o pcem.cfg e modifique a linha confirm_on_stop_emulation = 1 para 0.
Se existir um arquivo chamado flash.bin na pasta /roms/ga686bx/, delete ele.



Agora, no libTAS, tenha certeza de que a opção Prevent writing to disk está marcado, e modifique os Frames para 100/1.

Command-line options: --config /home/<USER>/.pcem/configs/WIN95.cfg
