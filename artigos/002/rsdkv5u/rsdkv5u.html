RSDKv5U - Chimera Tutorial

Core: RSDKv5U Chimera Core

1. Getting Started

If you launch RSDKv5U.exe with the original Sonic1u.rsdk DataPack, the game will run without sound.

This happens because audio in Sonic Origins is handled by the Hedgehog Engine 2, rather than directly by RSDKv5U.

Reference: RSDKv5 Decompilation FAQ

To get the game working properly, we need to run the decompilation in Using Data Folder mode. This requires unpacking the original .rsdk DataPacks using a tool called RetroED.

RetroED: https://github.com/RSDKModding/RetroED

2. Extracting the Sonic Origins DataPacks

Navigate to your Sonic Origins installation directory:

\image\x64\raw\retro\

You should find the following files:

  • Sonic1u.rsdk
  • Sonic2u.rsdk
  • SonicCDu.rsdk

For this example, we will use Sonic 1.

  1. Open RetroED and navigate to Tools > RSDK Unpacker.
  2. Under Select DataPack, select Sonic1u.rsdk.
  3. Load the corresponding RSDKv5UFileList.txt.
  4. Select Export DataPack.

This will extract the game's Bytecode and Data files.

Once extracted, place RSDKv5U.exe in the same directory as the two extracted folders.

At this point, launching the executable should run the game correctly, but there will still be no sound.

3. Restoring Music and Sound Effects

Since Sonic Origins uses the Hedgehog Engine 2 for audio management, we need to retrieve the original audio files from an earlier version of the game.

For this example, we will use Sonic the Hedgehog (2013).

Open RetroED again and repeat the extraction process, this time using:

  • Data.rsdk
  • RSDKv4FileList.txt

After extraction, navigate to the Data directory. You should find two important folders:

  • Music
  • SoundFX

Copy both folders into the Data directory extracted from Sonic Origins.

The music and original sound effects should now be available. However, Sonic Origins Plus introduced additional sound effects that are not present in the original 2013 release. We need to retrieve those separately.

4. Extracting the Additional Sound Effects (Origins Plus)

The easiest method I found for extracting the additional sound effects is described in the following tutorial:

GameBanana - Sound Effects Extraction Tutorial

By following this procedure, you should be able to obtain the Data/SoundFX/ directory directly from Sonic Origins Plus.

The following files contain the sound effect references extracted from Data/Game/GameConfig.bin in Sonic Origins Plus:

  • S1_GameConfig.txt
  • S2_GameConfig.txt
  • SCD_GameConfig.txt

You will need to manually compare the SoundFX entries and identify which sound effects are missing from the original Sonic 2013 files.

Copy the additional sound effects into the corresponding Data/SoundFX/ directory.

5. Final Setup

That's it! RSDKv5U should now be able to run the game with its music and sound effects restored.

To use it with the Chimera core, simply ZIP the complete extracted game directory and load it through Chimera.

Known Issues and Limitations

Sonic the Hedgehog 3

  • Currently does not work.

Sonic CD

  • The Rolling sound effect is missing.
  • A mod is required to fix this issue, even when using the 2011 version.

Sonic 1

  • Drop Dash and Spin Dash are unavailable.
  • The game currently uses Classic Mode settings.
