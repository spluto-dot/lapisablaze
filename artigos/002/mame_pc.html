PC/AT 486 with CS4031 chipset

Alem da ROM em si ct486, a gente precisa de uma serie de Softwares e imagens de CD e HDD, aqui tem tudo o que voce precisa: https://pleasuredome.github.io/pleasuredome/mame/index.html

Coloque o ibm5170 e o ibm5170_hdd dentro da pasta ROMs mesmo



MAME vai pedir para voce apertar F1 e entrar na BIOS para fazer as configurações iniciais do seu PC.
No STANDARD CMOS use o PgUp/PgDn para habilitar o disquete.



Agora va até o AUTO DETECT HARD DISK, ele vai detectar a imagem do MS-DOS, aperte Y para aceitar, e Esc para cancelar a proxima verificação. WRITE TO CMOD AND EXIT



Aqui voce ja tem um DOS funcionando.



Aperte Ctrl+ScrLk para habilitar o menu do MAME va em Slot Devices e selecione isa2 sblaster1_0.



Reset System
Agora o Mouse, File Manager, Floppydisk1, [software list], IBM PC/AT floppy disk images, Mitsuomi Mouse Driver (v6.0), instale o Driver normalmente, F3 para outro Reset.




Vamos testar?




Agora o CD-ROM, Slot Devices e selecione board3:ide:ide:1 cdrom.

File Manager, Floppydisk1, [software list], IBM PC/AT floppy disk images, CD-ROM/DVD-ROM drive IDE/ATAPI interface V2.2, INSTALL, reinicie, e agora voce tem acesso ao CD-ROM pelo DOS tambem.
